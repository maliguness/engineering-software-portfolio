# What is not public, and why

This repository contains **only** text, diagrams and images written or produced for the portfolio. It contains no project source code and no project Git history.

| Not published | Reason |
|---|---|
| Source code and Git history of the projects | Active product work; some projects are prepared for release |
| Real personal, financial or client data | Privacy and confidentiality. All screenshots use synthetic or fictional data |
| Configuration: keys, tokens, environment files, service IDs, local paths, network details | Security |
| Raw test logs and result bundles | They contain machine-specific details; dated summaries are given instead |
| Reproductions of copyrighted sources (e.g. plates and plans from academic publications used in Side Reconstruction) | Copyright |
| Third-party logos and in-game imagery | Trademarks and copyright |
| Internal agent instructions and workflow configuration | Internal tooling; summarized in [ai-assisted-development.md](ai-assisted-development.md) |

Questions about a project, or a walkthrough of private code in an interview setting: contact me through LinkedIn.
