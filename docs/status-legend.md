# Status legend

| Status | Meaning |
|---|---|
| **Completed** | Scope finished and verified; no active development. |
| **Completed samples** | Self-contained sample deliverables built on synthetic data; finished as samples, not client work. |
| **In development** | Working software with active milestones; not released to the public. |
| **In development · release prep** | Core features are implemented and tested, and work focuses on release readiness (legal, privacy, store setup, final QA). **Not yet published** in any app store. |
| **In development · paused** | Working software with verified milestones; development is paused and open release gates remain. |
| **Research prototype** | Built to answer a technical question under a documented evaluation process; results are real but scope is partial. |
| **Prototype** | A playable or runnable vertical slice that proves the core idea; not production-ready. |
| **Early prototype** | Setup and first assets exist; core behaviour is not yet demonstrated by evidence. |
| **In use · personal setup** | My working development environment; described for its design, not offered as a product. |

## Evidence labels

| Label | Meaning |
|---|---|
| **RE-RUN** | Re-executed for this portfolio on the stated date. |
| **RECORDED** | Taken from the project's own dated test/QA report; not re-run for this portfolio. |
| **STATIC** | Counted from source files (e.g. number of test declarations); says nothing about pass/fail. |
| **CI** | Result recorded by GitHub Actions on the stated date. |
| **NOT VERIFIED** | Stated but not yet proven; listed openly. |
